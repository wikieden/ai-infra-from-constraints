第 03 章 · 分块：一个数从显存读一次，在近处被用 t 次

配套讲义：第 03 章 · 从存储程序到数据流执行：存储层次就像大楼里的厕所。播放演示 n = 4、t = 2 的矩阵乘法 C = A × B；"远处"是显存，"近处"是 shared memory。

2

看点：① 每一帧，A 的一个块和 B 的一个块被搬进近处（远处读取 +2t²）；② 搬进来的每个数在近处被用 t 次，C 的块累加一次；③ 沿 K 方向滑 n/t 次，一个 C 块算完，再换下一个；④ 全部算完：远处读取 = 2n³/t。滑块：n = 8 时 t = 1、2、4、8，远处读取 1024 → 512 → 256 → 128，每翻一倍减半。
