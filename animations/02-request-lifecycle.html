第 02 章 · 一次生成请求：路由到实例，prefill 一次、decode 一步一步；权重加载 1 次、读 N 次

配套讲义：第 02 章 · 一次生成请求的处理过程：权重加载一次，每个 token 都要再读一遍。KV = Key–Value（键–值）；HBM = High Bandwidth Memory（高带宽内存，GPU 显存）。输入 4 个 token、实例排队数是编的；16.38 GB、15.14 GB 是原书 Qwen3-8B BF16 的数。

8

看点：① 入口检查后，路由器把请求派给更闲的实例 B；② 实例里先在 CPU 这边切 token、排队、编 batch、留 KV 空间，再把算子提交给 GPU；③ 权重从存储加载进显存只有 1 次；④ prefill：4 个输入 token 一次前向，KV 一下子有 4 份，出第 1 个 token；⑤ 每个 decode 步只送 1 个 token：权重读一遍、整份 KV 读一遍、KV 多一份、流式送出一个 token。滑块：输出 N 个 token，前向 N 次、读权重 N 次，加载始终 1 次，KV = 4 + N − 1 份。
